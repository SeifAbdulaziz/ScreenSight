How It Works

Three deterministic stages from webcam pixel to OS keyboard focus—with zero cloud requests and zero disk writes.

01

Arrange & Calibrate

Match your physical desk layout—side-by-side, portrait, or vertically stacked—in Arrange mode, then glance naturally at each display once to lock its (yaw, pitch) anchor.

deskPos layout · 1-pass calibration
02

Local Two-Stage AI Tracking

Windows Media Foundation captures volatile-RAM frames at 15 FPS. Stage 1 YuNet detects your face; Stage 2 FSANet estimates smoothed 3D head pose before discarding every frame immediately.

face_detector.onnx + head_pose.onnx
03

Instant, Safe Focus Switching

Once gaze clears your hysteresis margin and dwell timer, Win32 filters cloaked windows and transfers foreground focus cleanly via AttachThreadInput, auto-pausing during fullscreen games or calls.

DWMWA_CLOAKED · ConsentStore Auto-Yield

Windows SmartScreen Note: Open-source releases are unsigned. If Windows shows “Windows protected your PC”, click More info → Run anyway, or verify the file against the release SHA-256 checksums.

Build from Source

Requires Rust MSVC, Visual Studio Build Tools (C++), Node.js LTS, and WebView2 on Windows 10/11. 

git clone https://github.com/SeifAbdulaziz/ScreenSight.git
cd ScreenSight
npm install
cargo tauri build

Outputs are written under src-tauri/target/release/bundle/ (msi/ & nsis/).
